# 📚  Library Assistant Bot

A modern, chatbot-inspired Library Management System built with **Java Swing**.

## 🛠️ Data Structures Used
- **Linked List:** Used to store and traverse the catalog of 115 books.
- **Stack:** Implemented to handle the **Undo** functionality for borrow/return actions.

## ✨ Features
- **Aesthetic UI:** Space-Blue dark mode theme with rounded message bubbles.
- **Quick Actions:** Dashboard buttons for easy navigation.
- **Dynamic Search:** Real-time search across the entire library.
- **Pre-loaded Data:** 15 Classics + 100 auto-generated books.

## 🚀 How to Run
1. Open `chatbot.java` in VS Code.
2. Ensure JDK is installed.
3. Click **Run** or press `F5`.
